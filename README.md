# public-pages

A public repository for hosting static pages via GitHub Pages. Each folder represents a category of shareable content.

## Structure

```
public-pages/
└── travel-plans/       # HTML travel itineraries to share with friends
```

## Travel Plans

Self-contained HTML pages generated from trip planning. Each file is a full itinerary for a specific trip — shareable as a direct link.

| File | Trip |             |
|------|------|-------------|
| `rotterdam-plan.html` | Rotterdam | june 2026   |
| `roma-napoles-plan.html` | Rome & Naples | april 2026 |
